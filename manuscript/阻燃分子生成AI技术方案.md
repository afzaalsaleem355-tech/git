# 阻燃分子结构生成式 AI —— 技术方案

> 项目定位：输入目标阻燃性能要求，AI 生成/推荐**结构新颖、化学可行、可合成**的候选分子结构。
> 文档版本：v1.0（规划稿）
> 日期：2026-09-09

---

## 1. 项目概述

### 1.1 背景

阻燃材料广泛用于电子电器、建筑、交通、航空等领域。传统阻燃剂设计依赖经验试错，周期长、成本高。生成式 AI 可以：

1. 从已有阻燃剂数据中学习「结构 ↔ 性能」规律；
2. 在巨大化学空间中定向搜索；
3. 生成人类专家未必能想到的新结构。

### 1.2 项目目标

**总体目标**：搭建一套「目标性能 → 候选分子」的生成式分子设计系统。

**分阶段目标**：

| 阶段 | 目标 | 成功标准 |
|---|---|---|
| P0 | 建立「分子结构 → 阻燃相关性质」预测器 | 测试集 R² > 0.7 / 分类 AUC > 0.8 |
| P1 | 受限生成：基于已知阻燃骨架做修饰 | 生成分子中 > 80% 合法、可合成、新颖 |
| P2 | 无约束生成 + 多目标筛选 | 输出 Top-N 候选，附带性质与合成性评分 |
| P3 | 计算验证 +（可选）主动学习闭环 | DFT/MD 验证通过，形成完整 pipeline |

### 1.3 范围与边界

**本方案聚焦**：阻燃**添加剂小分子**（磷系、磷氮系、卤系、无机杂化等）的生成式设计。后续可扩展至阻燃单体与阻燃聚合物。

**明确不包含**（初期）：
- 全流程湿法合成实验；
- 成品材料级（LOI/UL-94/锥形量热）端到端精确预测（数据不足，作为后期目标）。

## 2. 需求与技术指标定义

### 2.1 目标性能（可配置）

| 指标 | 说明 | 可计算/可测性 |
|---|---|---|
| LOI（极限氧指数） | 材料阻燃性的核心指标，LOI ≥ 28% 通常视为难燃 | 难直接计算，需替代模型 |
| UL-94 等级 | V-0 / V-1 / V-2 / HB | 难直接计算，需替代模型 |
| 成炭率（Char Yield） | 凝聚相阻燃的关键 | **可近似预测（TGA/结构）** |
| 热分解温度 Td | 热稳定性 | **可近似预测** |
| 磷/氮/卤素含量 | 阻燃元素占比 | **可直接从结构计算** |
| 低烟低毒、无卤 | 环保约束 | 结构约束可编码 |
| 可合成性 | SAscore / 逆合成 | **可计算** |

**关键结论**：初期生成目标应优先使用「可直接从结构计算 + 可近似预测」的指标（成炭率、Td、元素组成、可合成性），LOI/UL-94 作为后期用 QSPR 迁移模型逼近的目标。

### 2.2 约束条件（编码进打分函数）

1. **合法性**：价键正确、无违规官能团（RDKit 校验 + SELFIES 保证）。
2. **稳定性**：无高应变环、无过氧化等不稳定基团。
3. **可合成性**：SAscore 阈值、逆合成可解。
4. **新颖性**：与已知分子相似度低于阈值（规避专利/已有结构）。
5. **成本/毒性**：排除卤素（若要求无卤）、排除已知毒性基团。

## 3. 总体技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                       用户需求输入                            │
│        （目标 LOI、成炭率、Td、无卤、含磷等约束）              │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ ② 分子表示层：SMILES / SELFIES / 图 / 3D 构象                │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ ③ 性质预测器（Surrogate Model）：                             │
│     GNN / 描述符模型 → 成炭率、Td、LOI(迁移)、可合成性        │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ ④ 生成模型（Generator）：                                     │
│     VAE + RL/贝叶斯优化 ｜ 扩散模型 ｜ 自回归 Transformer      │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ ⑤ 候选筛选层：合法性、稳定性、可合成性、新颖性、多目标打分      │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ ⑥ 验证层：DFT（热力学/键能）、MD（分解/成炭） → 输出报告       │
└─────────────────────────────────────────────────────────────┘
```

数据流贯穿始终：**数据层 ① 提供训练与评估依据，验证层 ⑥ 的结果回灌训练集形成闭环。**

## 4. 数据方案（最重要的一环）

### 4.1 数据来源

| 来源 | 内容 | 用途 |
|---|---|---|
| PubChem | 化合物结构 + 少量性质 | 通用化学空间、预训练 |
| ChEMBL | 生物活性数据 | 迁移学习特征 |
| 文献阻燃剂数据集 | LOI / UL-94 / 成炭率 / Td（需人工挖掘） | **核心监督数据** |
| 商业/专利数据库 | 阻燃剂结构 | 新颖性判断、骨架库 |
| QM9 / GEOM | 3D 构象、DFT 性质 | 预训练、稳定性标注 |
| 自建 TGA/实验数据 | 实验室积累 | 高价值私有数据 |

### 4.2 数据处理流程

1. **结构标准化**：InChI / 规范 SMILES 去重，去除盐、溶剂、同位素。
2. **合法性过滤**：RDKit 解析、SELFIES 编码校验、去除违规结构。
3. **标签对齐**：同一性质统一单位与测试条件（LOI 测试条件、TGA 升温速率等）。
4. **去泄漏**：基于分子骨架（Murcko scaffold）划分训练/验证/测试集，避免相似分子泄漏。

### 4.3 数据不足的应对策略（核心）

阻燃「结构—性能」成对数据稀缺，必须组合使用：

1. **多任务学习**：让一个模型同时学习成炭率、Td、LOI 等多个相关任务，共享表征。
2. **预训练 + 微调**：在大化学空间（PubChem 数百万分子）上做自监督预训练，再在少量阻燃数据上微调。
3. **弱监督/规则标注**：用「含磷、含氮、芳环成炭」等化学规则生成弱标签。
4. **主动学习**：优先实验验证模型最不确定的候选，用真实结果增量训练。

### 4.4 里程碑数据规模

| 阶段 | 最少可用数据 | 推荐规模 |
|---|---|---|
| 起步验证 | 300–500 条带标签分子 | 1000+ 条 |
| 可靠预测器 | 1000–2000 条 | 5000+ 条 |
| 生成模型训练 | 可与预测器共用，另加大规模无标签库 | 10⁵–10⁶ 无标签分子 |

## 5. 分子表示

| 表示 | 优点 | 缺点 | 用途 |
|---|---|---|---|
| SMILES | 通用、易读、库支持好 | 生成易产生非法串 | 存储、输入输出 |
| **SELFIES** | **生成永远合法** | 词汇表偏大 | **生成模型首选** |
| 分子图（原子/键） | 保留拓扑结构、GNN 友好 | 生成复杂度高 | 性质预测、图生成 |
| 3D 构象 | 含立体/构象信息 | 计算昂贵 | DFT/MD、3D 生成 |

**建议**：**SELFIES 用于生成，图用于性质预测，SMILES 用于人机交互与数据库存储。**

---

## 6. 性质预测器（先做，再谈生成）

### 6.1 模型候选

| 模型 | 适用 | 说明 |
|---|---|---|
| 描述符 + 随机森林/XGBoost | 小数据、可解释 | 基线，必做 |
| 分子指纹 + 神经网络 | 中数据 | 快速迭代 |
| 图神经网络（GNN：GCN/GIN/MPNN） | 结构相关性质 | 主力模型 |
| 预训练 GNN（MolCLR 等） | 数据稀缺 | 迁移学习 |
| 多任务学习网络 | 多性质相关 | 提高泛化 |

### 6.2 评估与防泄漏

- 按 Murcko 骨架划分数据集；
- 指标：回归用 R²/MAE/RMSE，分类用 AUC/F1；
- 报告模型不确定性（集成/贝叶斯），用于主动学习。

## 7. 生成模型

### 7.1 路线 A：VAE + 强化学习 / 贝叶斯优化（推荐起步）

- 在 SELFIES 空间训练 VAE，得到连续潜在空间；
- 用性质预测器做打分函数（reward）；
- 在潜在空间做贝叶斯优化（BO）或强化学习（RL）搜索高分区域；
- 优点：稳定、易实现、可解释、易于多目标；
- 缺点：探索能力弱于扩散模型，新颖性受 VAE 影响。

### 7.2 路线 B：扩散模型 / 自回归 Transformer（进阶）

- 条件扩散模型（如 EDM、DiGress）或自回归生成（如 GPT 式 SMILES 生成）；
- 直接以「目标性质」作为条件生成分子；
- 优点：生成质量和多样性好；
- 缺点：训练成本高、需要更多数据、条件控制更难。

### 7.3 路线 C：骨架修饰 / 片段拼接（快速见效）

- 基于已知阻燃骨架（DOPO、磷酸酯、三聚氰胺盐、环三磷腈等），用规则或模型做官能团替换；
- 优点：结果可解释、可合成性高；
- 缺点：新颖性受限。

**推荐策略**：P1 用路线 C 快速验证闭环；P2 用路线 A 做主生成器；P3 视数据量引入路线 B。

### 7.4 多目标优化

打分函数加权：

```
Score = w1·阻燃性 + w2·可合成性 + w3·新颖性 + w4·(安全性/环保) - 惩罚项
```

用 Pareto 前沿筛选非支配解，输出多个候选供专家挑选。

## 8. 候选筛选与评分

生成 → 依次过滤：

1. **合法性**：RDKit/SELFIES 校验；
2. **稳定性**：规则库（高应变环、过氧键、叠氮等）剔除；
3. **可合成性**：SAscore ≤ 阈值、逆合成工具（AiZynthFinder）可解；
4. **新颖性**：与已知库 Tanimoto 相似度 ≤ 阈值；
5. **专利规避**：与专利分子相似度检查（后期）；
6. **多目标打分**：按 7.4 排序，输出 Top-N + Pareto 前沿。

## 9. 计算验证

| 方法 | 工具 | 验证内容 | 成本 |
|---|---|---|---|
| 分子力学/半经验 | RDKit, xTB | 构象、几何合理性 | 低 |
| DFT | ORCA, Gaussian, VASP | 热力学稳定性、键解离能（BDE）、HOMO/LUMO | 中高 |
| 分子动力学 MD | GROMACS, LAMMPS | 热分解、成炭行为、与基体相容性 | 高 |

**用途**：对 Top 候选做快速 DFT 稳定性/键能筛选，进一步缩小进入实验的名单；结果回灌训练集。

---

## 10. 实验验证与主动学习闭环（后期）

1. 对计算验证后的 Top 候选做小规模合成与表征（LOI、UL-94、TGA）；
2. 将真实实验结果与模型预测对比；
3. 用主动学习选择「模型最不确定 + 高价值」的下一批候选；
4. 迭代更新性质预测器与生成器。

## 13. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 阻燃数据严重不足 | 预测器不可靠 | 多任务/迁移学习、弱监督、自建小数据集 |
| LOI/UL-94 不可直接预测 | 目标失真 | 用成炭率/Td/元素组成做代理目标，逐步逼近 |
| 生成分子不可合成 | 结果无价值 | 强合成性过滤 + 骨架修饰起步 |
| 生成分子「新颖」但无意义 | 浪费资源 | 引入化学规则约束 + 领域专家评审 |
| 专利侵权 | 法律风险 | 新颖性/相似度检查，后期专利检索 |
