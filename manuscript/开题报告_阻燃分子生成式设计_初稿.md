## 二、选题背景与研究意义

### 2.1 选题背景

聚对苯二甲酸乙二醇酯（PET）因优异的力学性能、耐热性、电绝缘性和成本优势，广泛用于纤维、薄膜、包装和工程塑料领域【补充：行业规模/产量数据，需核实】。然而，PET 本身可燃，其极限氧指数（LOI）约为 21% 左右，在电子电器、交通工具、建筑材料等对阻燃有明确要求的场景中，必须进行阻燃改性【LOI 数值需核实】。

传统的阻燃剂设计主要依赖"经验试错 + 反复合成测试"，存在以下问题：

1. **周期长、成本高**：一个候选阻燃剂从设计到完成合成与阻燃测试，周期以月计；
2. **化学空间巨大**：可能的有机分子数量远超人工能够穷举的范围，人类经验只能覆盖其中极小一部分；
3. **多目标矛盾突出**：阻燃性能、热稳定性（PET 加工温度高）、与基体相容性、可合成性、成本、环保性（无卤化）往往相互制约。

生成式人工智能为分子设计提供了新范式：通过学习"分子结构—性能"的映射关系，在巨大化学空间中**定向搜索并生成结构新颖、化学可行、可合成且满足目标性能的候选分子**。这一范式在药物分子设计领域已取得显著进展，但在阻燃材料领域仍处于起步阶段，具有明确的研究空间。

### 2.2 研究意义

**理论意义**：阻燃材料的"结构—性能"关系具有多机理耦合、强基体依赖的特点，且高质量成对数据稀缺。本研究针对该特点，探索**数据稀缺条件下的阻燃分子生成式设计方法**，为材料领域的分子逆设计提供方法学参考。

**应用意义**：PET 的阻燃改性具有迫切工业需求。本研究所建立的"目标性能 → 候选分子"设计方法，有望缩短阻燃剂研发周期、降低研发成本，并服务于**无卤环保阻燃**的发展趋势。

## 三、国内外研究现状

### 3.1 PET 阻燃改性研究现状

PET 的阻燃改性主要有两类思路：**本征型（反应型）**与**添加型**。

- **磷系阻燃剂**：以 9,10-二氢-9-氧杂-10-磷杂菲-10-氧化物（DOPO）及其衍生物为代表。磷系阻燃剂可在凝聚相促进成炭、在气相捕获自由基，且低烟低毒，符合无卤化趋势。DOPO 的活性 P–H 键可引入双键、羟基、羧基等官能团，通过共聚反应嵌入 PET 分子链，赋予持久阻燃性【补充：DOPO 阻燃 PET 的代表性文献，需检索核实】。
- **氮系与磷氮协同体系**：三聚氰胺及其衍生物、磷腈类化合物等，常与磷系复配，利用磷氮协同效应提高成炭效率。
- **无机与纳米阻燃剂**：金属氢氧化物、蒙脱土、层状双金属氢氧化物（LDH）等，通常需要较高添加量，对力学性能影响较大。

**存在的主要问题**：现有研究多为"针对某一类结构做实验改性"，缺乏系统性的、数据驱动的分子结构设计方法，新结构主要依赖人工经验提出。

### 3.2 分子生成式设计方法研究现状

分子生成式设计（de novo molecular design）的核心思想是：在分子表示空间中建立生成模型，并结合性质预测器（surrogate model）作为目标函数进行优化。代表性方法包括：

1. **变分自编码器（VAE）**：Gómez-Bombarelli 等提出基于 SMILES 连续隐空间表示的自动化学设计，通过潜在空间上的优化实现分子的定向生成 [1]；
2. **循环神经网络 / 自回归模型**：Segler 等利用 RNN 在 SMILES 序列上生成聚焦的分子库 [2]；
3. **分子字符串表示**：Krenn 等提出 SELFIES 表示，保证生成字符串 100% 对应合法分子 [3]；
4. **基准与平台**：MOSES [4]、GuacaMol [5] 等为分子生成模型提供了统一评测基准；
5. **图生成与扩散模型**：以图神经网络为基础的分子的图生成，以及近年兴起的扩散模型，进一步提升了生成质量【补充：代表文献】。

在优化目标方面，除预测性能外，研究普遍引入**可合成性**（如 SAscore [6]）与**新颖性**约束，以筛选出既性能优良、又切实可行的分子。

### 3.3 阻燃领域的机器学习研究现状

机器学习在阻燃材料中的应用集中在**定量结构—性能关系（QSPR）**建模，例如以分子描述符预测成炭率、热分解温度、LOI 等指标【补充：阻燃 QSPR 代表性文献，需检索核实】。但现有工作存在以下不足：

1. 高质量"结构—阻燃性能"成对数据稀缺且格式不统一；
2. 多数工作止步于**预测**，未与**生成**结合，未能形成"目标性能→新结构"的逆设计闭环；
3. 缺乏面向特定聚合物基体（如 PET）的生成式设计研究。

### 3.4 研究空白与本课题切入点

综上，本课题的切入点是：**面向 PET 体系、以磷系阻燃分子为对象，针对数据稀缺问题，构建"结构—性能"代理预测模型，并与多约束分子生成相结合，建立可合成、可验证的阻燃分子逆设计闭环。**

## 四、研究目标、研究内容与拟解决的关键问题

### 4.1 研究目标

建立一套面向 PET 的磷系阻燃分子生成式设计方法：给定目标阻燃相关性能（成炭率、热稳定性、磷/氮含量等），能够**生成/推荐结构新颖、化学可行、可合成的新候选分子**，并完成计算层面的初步验证。

### 4.2 研究内容

**研究内容一：PET 用磷系阻燃分子结构—性能数据集的构建与标准化**

- 从文献、公开数据库（PubChem 等）收集磷系/磷氮系阻燃剂分子的结构与性能信息；
- 建立结构标准化、去重、合法性校验流程；
- 按分子骨架（Murcko scaffold）划分数据集，避免训练/测试泄漏；
- 针对"成炭率、热分解温度、LOI"等指标整理成对的监督数据。

**研究内容二：数据稀缺条件下的"分子结构→阻燃性"代理预测模型**

- 构建"分子指纹 + 阻燃相关领域描述符（含磷量、含氮量、芳环数等）"的特征表示；
- 对比描述符基线模型、图神经网络、预训练迁移模型在小样本下的性能；
- 重点研究**预训练大化学空间 + 小样本阻燃数据微调**的迁移学习策略，缓解数据稀缺问题。

**研究内容三：多约束的阻燃分子生成与筛选**

- 以 SELFIES 等保证合法性的分子表示为基础，构建生成式模型（组合枚举为基线，逐步引入 VAE/遗传算法/扩散模型）；
- 设计"阻燃性 + 可合成性 + 新颖性 + 无卤环保"的多目标打分函数；
- 对生成候选进行合法性、稳定性、可合成性（SAscore、逆合成）、新颖性多级过滤，输出 Top-N 候选。

**研究内容四：候选分子的计算验证**

- 对 Top 候选分子进行密度泛函理论（DFT）计算，评估热力学稳定性与关键键解离能；
- 必要时结合分子动力学（MD）初步评估成炭/热分解行为；
- 形成"生成—筛选—计算验证"闭环，并回灌数据集。

### 4.3 拟解决的关键问题

1. **关键问题一**：阻燃"结构—性能"成对数据稀缺且指标难以直接从单分子计算，如何建立可靠、可泛化的代理预测模型？
2. **关键问题二**：如何保证生成分子**结构合法、化学稳定、可合成、且与 PET 体系匹配**（热稳定性满足加工温度要求）？
3. **关键问题三**：如何将阻燃性、可合成性、新颖性等多个相互制约的目标进行有效联合优化，输出切实可行的候选？

## 五、研究方法与技术路线

### 5.1 总体技术路线

```
目标设定（成炭率/Td/磷氮含量，PET 体系）
        │
        ▼
[数据层] 数据采集、清洗、标准化、骨架划分
        │
        ▼
[表示层] SMILES / SELFIES / 分子图 + 领域描述符
        │
        ▼
[预测层] 代理预测模型（描述符基线 → GNN → 预训练迁移）
        │
        ▼
[生成层] 组合枚举（基线）→ VAE/遗传算法/扩散模型
        │
        ▼
[筛选层] 合法性/稳定性/可合成性/新颖性 + 多目标打分
        │
        ▼
[验证层] DFT/MD 计算验证 → 输出候选分子报告
```

### 5.2 关键方法与工具

| 环节 | 方法/工具 |
|---|---|
| 化学信息学 | RDKit、Open Babel |
| 分子表示 | SMILES、SELFIES、Morgan 指纹 |
| 性质预测 | 随机森林/梯度提升（基线）、图神经网络（GNN）、预训练迁移模型 |
| 分子生成 | 组合枚举（基线）、VAE + 贝叶斯优化/强化学习、扩散模型（进阶） |
| 可合成性 | SAscore、AiZynthFinder 逆合成 |
| 计算验证 | xTB、ORCA（DFT）、GROMACS（MD） |
| 平台 | PyTorch、scikit-learn、MLflow、DVC |

### 5.3 预实验（可行性验证）

为验证上述技术路线的可行性，已开展最小预实验：

- **数据**：手工整理 63 个阻燃相关真实分子（磷系/磷氮系/芳香成炭/酯类/脂肪族对照）；
- **标签**：以透明专家规则构造"阻燃性代理分数"（芳环数 + 含磷量 + 含氮量 + 杂环 + 氧含量 − 脂肪链惩罚）；
- **特征**：Morgan 指纹 + 11 维领域描述符；
- **预测器**：随机森林，5 折交叉验证；
- **生成**：芳香骨架 × 阻燃官能团组合枚举（2260 个组合），经合法性/无卤/分子量/SAscore/新颖性过滤。

**预实验结果**：

| 指标 | 结果 |
|---|---|
| 预测器 R²（5 折 CV） | 0.778（MAE 0.063） |
| 生成规模 | 2260 组合 → 574 合法候选 → 443 新颖候选 |
| Top 候选 | 三嗪环 + 磷酸/膦酸基团，SAscore 2–3（易合成） |

预实验初步证明了"数据 → 预测 → 生成 → 筛选"闭环的技术可行性，为后续正式研究奠定了基础。需要说明的是，预实验标签为代理分数，正式研究将替换为真实阻燃数据。

## 六、可行性分析

1. **技术可行性**：所采用的方法均为成熟开源工具（RDKit、SELFIES、scikit-learn、PyTorch、ORCA 等），分子生成式设计在药物领域已有大量可借鉴的方法，本课题属于"迁移应用 + 领域改进"，而非从零发明。
2. **数据可行性**：不直接依赖稀缺的 LOI 大数据，采用"可计算代理指标 + 领域描述符 + 迁移学习"策略，300–500 条带标签数据即可起步，且预实验已用 63 条数据跑通流程。
3. **算力可行性**：生成模型训练仅需单张消费级 GPU；DFT 计算针对少量 Top 候选进行，计算量可控。
4. **进度可行性**：研究内容按里程碑分解，各阶段均有独立可交付成果，风险可控。
5. **预研基础**：已完成最小预实验，验证了核心流程的可行性（见 5.3）。

## 七、创新点

1. **针对阻燃数据稀缺，提出"分子指纹 + 阻燃领域描述符 + 预训练迁移"的小样本代理预测建模策略**，区别于通用 QSPR 建模，显式引入含磷量、含氮量、芳环数等阻燃相关先验知识。
2. **面向 PET 体系，构建"阻燃性 + 可合成性 + 新颖性 + 无卤环保"多约束的分子生成与筛选策略**，使生成结果兼顾性能与工程可行性。
3. **形成"生成—筛选—计算验证（DFT/MD）"的阻燃分子逆设计闭环**，并产出若干经计算验证的新候选分子结构。
