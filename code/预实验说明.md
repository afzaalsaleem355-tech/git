# 最小预实验：面向 PET 的阻燃分子生成式设计

这是为硕士开题报告准备的**端到端最小可行性验证（Proof of Concept）**，
证明「数据 → 性质预测 → 生成 → 筛选」整条技术路线能跑通。

## 一、做了什么

| 环节 | 实现 |
|---|---|
| 数据 | 手工整理 63 个阻燃相关真实分子（磷系/磷氮系/芳香成炭/酯类/脂肪族对照） |
| 标签 | 专家规则构造的「阻燃性代理分数」（透明公式，见下） |
| 特征 | Morgan 指纹(1024) + 领域描述符（含磷量/含氮量/芳环数/MW 等 11 维） |
| 预测器 | 随机森林回归（对照 Ridge 基线），5 折交叉验证 |
| 生成器 | 芳香骨架 × 阻燃官能团 组合枚举（2260 个组合） |
| 筛选 | 合法性、无卤、分子量、可合成性 SAscore ≤ 6、新颖性 |

## 二、代理标签公式（透明、可复现）

```
score = 0.25·tanh(芳环数/2) + 0.30·tanh(含磷原子数)
      + 0.20·tanh(含氮原子数/2) + 0.10·tanh(芳杂环数/2)
      + 0.05·环数贡献 + 0.05·芳香碳占比 + 0.05·tanh(含氧数/4)
      − 0.15·tanh(脂肪碳数/8)
```

**重要**：这是「代理标签」，用来验证流程。正式研究中要替换为真实的
成炭率(TGA)、热分解温度、LOI 等实验数据。

## 三、结果

```
预测器  随机森林  R²=0.778  MAE=0.063（5折CV）
        Ridge基线 R²=0.776
生成    2260 组合 → 574 个合法候选 → 443 个新颖候选(相似度<0.5)
```

Top 新颖候选以「三嗪环 + 磷酸/膦酸基团」为主，SAscore 2–3（易合成），
属于文献中常见的磷氮协同阻燃结构，说明方法能生成合理的候选分子。

## 六、诚实声明与后续工作

1. 标签为代理分数，非真实阻燃数据 —— 后续替换。
2. 生成器是组合枚举（可解释、可合成），作为基线；更高级的
   VAE/遗传算法/扩散模型作为论文的「方法改进」章节。
3. 早期尝试的朴素 SELFIES 随机变异会生成化学上不合理的结构
   （累积双键、端基裸磷），已改用组合枚举规避 —— 这个"踩坑"过程
   本身可作为开题报告里"方法选择依据"的说明。
